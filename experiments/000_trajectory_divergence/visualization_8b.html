Reading the map

Each node is one generation. Horizontal position is temperature. Vertical position groups similar continuation behavior. Edges connect lexically similar outputs from the same prompt variant.

Key quantities

Lexical diversity = unique words / total words. Similarity = Jaccard overlap between output word sets.
