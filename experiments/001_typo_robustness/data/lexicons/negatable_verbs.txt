# Copula and auxiliary verbs targeted by the MCQ Regime-C negation operation.
#
# The negation rule inserts "not" immediately after the first match of these
# words that is NOT already followed by "not" (so "is not" is skipped).
# The regex built from this list uses a negative lookahead (?! not).
#
# Coverage rationale (design/04 §4.7):
#   The list covers the English copula (is, are, was, were) and the modal/
#   aspectual auxiliaries most likely to appear as the main finite verb in
#   factual MCQ questions (does, do, can, will). "Would", "should", "must",
#   and "might" are excluded as they introduce epistemic hedges that interact
#   unpredictably with negation; their omission is documented here so it can
#   be audited.
#
#   Any future extension of this list requires a corresponding design-doc
#   amendment and a new version date below.
#
# Version: 2026-06-19 (pre-registration freeze)
# Implements: design/04 §4.7
# See also: data/lexicons/PROVENANCE.json
is
are
was
were
does
do
