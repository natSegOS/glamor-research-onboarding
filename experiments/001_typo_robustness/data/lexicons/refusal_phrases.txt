# Refusal phrases for ParseStatus.REFUSAL detection.
#
# Core set aligned with Zou et al. (2023) "Universal and Transferable
# Adversarial Attacks on Aligned Language Models" (NeurIPS), Appendix A.2,
# which establishes the standard refusal-detection methodology for adversarial
# robustness evaluation and is the most widely cited source for this
# classification task. Extended with math/QA-specific refusals that arise
# when perturbed prompts trigger inability responses rather than safety refusals.
#
# Guard: a match is only classified REFUSAL when no parseable answer is also
# present (design/04 §4.5). This prevents "I can't be certain but the answer
# is 19" from being misclassified. The proxy is conservative (under-counts)
# for the same reasons as clarification_phrases.txt.
#
# Implements: design/04 §4.5 — ParseStatus.REFUSAL detection
