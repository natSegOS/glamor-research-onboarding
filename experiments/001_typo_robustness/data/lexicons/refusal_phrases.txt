# Refusal phrases used to classify interactional failures.
#
# A generation matching any of these (as whole words, case-insensitive) AND
# containing no parseable answer is classified as ParseStatus.REFUSAL.
# The "no parseable answer" guard means a model that says "I can't be certain
# but the answer is 19" is still scored on its answer (design/04 §4.5).
#
# Pre-registration rationale (design/04 §4.5):
#   The list targets strong, unambiguous modal negations and the "as an AI"
#   formulaic opener that precede most refusal responses. It intentionally
#   excludes softer hedges ("I'm not sure") that often co-occur with a genuine
#   answer attempt.
#
#   As with clarification phrases, this is a conservative proxy: ICR is a
#   diagnostic metric and a lower-bound is more defensible than an upper-bound
#   when the primary endpoint is accuracy.
#
# Version: 2026-06-19 (pre-registration freeze)
# Implements: design/04 §4.5
