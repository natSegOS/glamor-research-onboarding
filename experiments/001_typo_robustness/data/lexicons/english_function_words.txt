# English closed-class function words for key_terms extraction in MCQ questions.
#
# Aligned with the stopword list in:
#   Manning, Raghavan & Schütze (2008) "Introduction to Information Retrieval"
#   (Cambridge University Press), Table 2.4 — the standard IR reference for
#   closed-class English words. The closed-class inventory is also grounded in:
#   Jurafsky & Martin (2023) "Speech and Language Processing" (3rd ed.) §2.4,
#   which gives the authoritative linguistic definition of closed-class words.
#
# Words are excluded from MCQ key_terms if they appear here, because function
# words carry grammatical rather than semantic information and are poor targets
# for the informative_word perturbation policy. Content words (nouns, main
# verbs, adjectives, domain terms) that are absent from this list remain
# eligible as key_terms.
#
# Only true closed-class words and their inflected/contracted forms are listed.
# Open-class words (even very common ones) are intentionally excluded.
#
# Implements: extract_key_terms_from_mcq_question in tasks/multiple_choice.py
